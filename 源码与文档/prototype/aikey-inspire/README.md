# AI KEY 灵感圈（光标交互 MVP）

对应需求：拿控制器当鼠标，躺在床上逛小红书、用 Google 搜东西；看到喜欢的，**圈起来、说明意图、存进灵感库**，再把灵感**丢进 agent**。另加一层 **Jev 点击预判**：陀螺仪指针不如鼠标准，光标停下时，Jev 判断你想点哪个按钮，并把它高亮出来。

原生 macOS 菜单栏 App（Swift），不占 Dock。控制器本身就是 HID 鼠标，“当鼠标用”不需要这个 App。

> **开发线**：2026-11-16 起灵感圈在分支 `claude/host-app-dev-refine-9d6a02` 单独迭代（从 E24 部署调试分支 `3d3c897` 拎出，路径不变）。E24 固件、`aikey-host` 网页上位机仍在各自的分支，不在这里改。

## 现在能做什么

| 功能 | 怎么用 | 说明 |
|---|---|---|
| 点击预判 | 移动光标后停住约 0.55 秒自动触发；`⌃⌥P` 立刻预判 | 用辅助功能读光标周围 150 px 内能点的元素（最多 20 个），交给 Jev 选一个，绿色框 = 置信度 ≥ 0.5，橙色 = 拿不准 |
| 点预判目标 | `⌃⌥↩` | 先对目标执行辅助功能的“按下”，不支持再在中心模拟一次点击 |
| 圈选 | `⌃⌥C` 开始 → 移动光标画圈 → `⌃⌥C` 完成，`Esc` 取消 | 截下圈住的范围，记录软件、窗口标题、网址、圈内文字 |
| 说明意图 | 圈完弹出输入框，回车保存 | 意图里写 `#标签` 会变成标签；有项目列表时可以直接选项目（默认“自动判断”） |
| 入库整理 | 保存后自动 | **一次** Jev 请求同时判断：类别（配色、排版、产品造型、交互、文案、摄影构图、素材、其他）、归属项目、你用过的标签哪些适用、和最像的几条旧灵感是不是同一条（见下方“灵感库整理”） |
| 灵感库 | `⌃⌥L` | 筛选、按任务召回、勾选打包、编辑、合并重复、归档；单张卡片仍可直接拖进 agent 对话框 |
| 调试面板 | `⌃⌥D` | 每次预判的候选、概率、置信度、耗时、请求 JSON；可写“当前目标”、标记猜对或猜错 |

### 快捷功能（键盘版，先摸链路）

| 快捷键 | 功能 |
|---|---|
| `⌃⌥S` | 快速搜索：弹搜索框，选中的文字自动填入；可先点名 小红书 / b站 / 推特 / 知乎 / 抖音 / YouTube / 百度 / 谷歌 / 页内 / 灵感库；没点名就搜当前网站，否则用 Google |
| `⌃⌥←` / `⌃⌥→` | 图片上一张 / 下一张；按住不放连续翻 |
| `⌃⌥1` / `⌃⌥2` | 点赞 / 收藏指针所在内容（排除评论区，已做过不重复点，5 秒内 `⌃⌥Z` 撤销） |
| `⌃⌥3` / `⌃⌥4` | 投币 / 关注（先弹确认框） |
| `⌃⌥G` | **目标模式**开 / 关（B2）：没有目标时先问“这次在找什么”。打开后屏上的信息流卡片按目标打相关度：相关的绿框（“正是”加粗），无关和推广的压暗，还在等 Jev 的虚线框。滚动时先撤掉标注，停下 0.5 s 后重扫；点击、按键后 1 s 重扫 |
| `⌃⌥N` | **下一条相关的**（B3）：跳到指针下方第一张相关卡片（同一行取右边），把指针放到卡片中间，直接按 L 就能打开；这一屏下面没有了就往下翻一屏 |
| `⌃⌥X` | **关闭弹窗**（B7）：在指针所在网页找弹窗（`role=dialog` 或 class / id 里有 modal、dialog、popup、mask 等），只按“关闭、×、暂不登录、以后再说、跳过、取消”这类按钮，含“登录、关注、确定、购买、删除”等字的一律不按；多个候选时问 Jev（J9），按完回读弹窗还在不在。找到弹窗却认不出按钮时发一次 Esc；没看到弹窗就什么都不做 |
| `⌃⌥K` | **打包所选**（K4）：把灵感库里勾选的几条复制给 agent；没勾选时打开灵感库 |

快速搜索（`⌃⌥S`）搜网站后，搜索词自动当目标并打开目标模式（功能定义 F1 第 5 步；“权限与设置”里可以关掉）。

完整清单见 [浏览场景功能定义 · 第 9 节](../../docs/engineering/项目档案/20261116-浏览场景功能定义/浏览场景功能定义.md)。

### 灵感库整理

| 环节 | 能做什么 |
|---|---|
| 理（K2） | 标签（`#标签`、编辑框、Jev 从你用过的标签里挑适用的，自动加的会标出来）；项目（“整理 → 管理项目”里建列表，入库时 Jev 判断归属，你自己选的不覆盖）；去重（代码先按网址、标题、圈内文字挑出最像的 3 条，再让 Jev 判断是不是同一条，≥ 0.7 标“可能重复”，在编辑框里“合并到那条”或“不是重复”） |
| 找（K3） | 筛选：类别、项目（含“未归属”）、标签、来源网站、时间（今天 / 7 天 / 30 天）、没用过、可能重复、显示归档；搜索框里空格分开的几个词都要出现。**按任务召回**：写一句任务（比如“根据我的参考重新生成 AI 控制器宣传 PPT”），当前筛选下最近 48 条每条一个 Jev Score（无关 / 沾边 / 相关 / 正是），按相关度排序，前 5 条绿框，“选中前 5 条”一键勾选 |
| 用（K4） | 勾选几条 → “打包复制”：剪贴板里第一项是按类别分组的整段说明（意图、项目、标签、来源、链接、圈内文字、截图路径），后面是各张截图文件；“导出文件夹”：截图按顺序编号 + `灵感参考.md`，整个文件夹拖进 agent |
| 回流（K5） | 复制、拖出、打包都记“用过 n 次”；“整理 → 归档 30 天没用过的”只是打标记，不删除，打开“显示归档”还能看到 |
| 回看（K6） | “回到原处”：打开原网页并带上文字片段 `#:~:text=`，支持的浏览器（Chrome、Edge、Safari）会直接滚到圈过的那段；找不到那段文字时照常打开页面 |

双击卡片或点铅笔打开编辑框：改意图、类别、项目、标签，归档、删除（移到废纸篓）、让 Jev 重新整理。旧版本存的灵感照样能读（新字段都是可选的）；“整理 → 让 Jev 整理没整理过的”可以一条一条补整理。

还没做：控制器 S 键圈选、按住 V 用语音（板上按键还没接好）；B5 页面筛查与段落定位；截图 + Box 兜底；吸附点击（待拍板）。

## Jev（TypeSafe）

- API Key 存在本机钥匙串（服务名 `com.aikey.inspire.typesafe`），App 的“权限与设置”里可以保存、测试、删除；也接受环境变量 `TYPESAFE_API_KEY`，环境变量优先。Key 不写日志，不进仓库。
- 没有 Key 时自动用**模拟模式**：只按距离和运动方向打分，用来调界面，不代表 Jev 的判断。
- 每次预判一个请求，两个问题并行：
  - `target`（Choice）：候选 `c1…cN` 加 `none`；
  - `about_to_click`（Noul）：是否正在瞄准某个要点的东西。
- 状态里有：软件名、窗口标题、网址、指针位置和停下前 0.5 秒的移动、候选（类型、文字、距离、方向、尺寸），以及可选的“当前目标”。**这些会发给 TypeSafe，截图不发。**
- 两次自动请求至少间隔 0.8 秒；同一位置、同一批候选不重复请求；指着灵感圈自己的窗口不预判。
- 新增的几种请求（都只发文字，不发截图）：

| 用在哪 | 题型 | 发出去的内容 | 实测（11-16，人造数据） |
|---|---|---|---|
| 入库整理 J6 + J7 | 类别 Choice、项目 Choice、每个标签一个 Noul、每条疑似重复一个 Noul，一次请求 | 新灵感的意图、软件、标题、网址、圈内文字；项目列表；最像的 ≤ 3 条旧灵感的同样字段 | 2.4 s（含首次握手）、1164 tok |
| 按任务召回 J8 | 每条一个 Score，每批 8 条并行 | 任务；每条的意图、类别、项目、标签、标题、圈内文字前 4 段 | 一批 0.4 s、2072 tok |
| 目标模式 J2 | 每张卡片一个 Score + 一个“是不是推广” Noul | 目标；页面标题、网址；每张卡片的文字（标题、作者、点赞数、图片说明） | 6 张 0.4 s、1595 tok |
| 关闭弹窗 J9 | Choice | 弹窗里的文字前 120 字；候选按钮的文字、class、大小 | 0.4 s、671 tok |

  目标模式按“目标 + 卡片文字”缓存，同一张卡不重复问；滚动中不问，停下才问。一屏 16 张卡片以内一次请求。

## 调试

- 日志：`~/Library/Logs/AIKeyInspire/predictions.jsonl`（每次预判一行：候选、概率、耗时、来源、是否过期）、`circles.jsonl`（圈选、保存、整理结果、召回、打包、合并、归档）、`actions.jsonl`（快速搜索、翻页、互动：去向、候选按钮、Jev 选择、按下方式、前后状态）、`browse.jsonl`（目标模式每次扫描的卡片数、耗时、Jev 结果；下一条；关闭弹窗的候选、选择、回读）、`app.jsonl`（每次启动的权限状态）、`selftest.jsonl`（`--jev-selftest` 的结果）。
- 灵感库：`~/Library/Application Support/AIKeyInspire/Library/<id>/`（`item.json` + `shot.png`），项目列表在 `Library/_meta/projects.json`，导出的打包文件夹在 `AIKeyInspire/Packs/`。删除会移到废纸篓。
- Jev 自检：`open "$HOME/Applications/AI KEY 灵感圈.app" --args --jev-selftest`，用人造数据把整理、召回、卡片、关闭弹窗四种请求各发一次，结果写进 `selftest.jsonl`（App 直接读自己钥匙串里的 Key，终端不用碰 Key）。
- 命令行探针（不用装 App；运行它的终端要有辅助功能权限）：

~/.cache/ai-key-inspire/build/release/inspire-probe scan

`cards` 列出指针所在网页的信息流卡片（`GOAL=…` 时附模拟相关度）；`popup` 列出指针所在网页的弹窗和关闭按钮（不点）；`browse <网址片段>` 在测试页 `Tests/fixtures/feed.html` 上跑卡片和弹窗查找（`PRESS=1` 时只在测试页上真按关闭并回读）；`demo2` 和 `--jev-selftest` 一样，但要终端能读到 Key。`search "文字" [网址]` 打印快速搜索的去向和网址（不打开）；`actions like|collect|coin|follow` 找指针所在页面的互动按钮（不点）；`flipfind [next|prev]` 找图集翻页按钮（不点）；`fixture <网址片段>` 在测试页 `Tests/fixtures/note.html` 上跑全部查找（`PRESS=1` 时只在测试页上真按）。测试页用 `.claude/launch.json` 里的 `inspire-fixture` 服务打开。

`scan` 枚举光标附近的候选并打印请求体；`watch` 跟随光标，每次停留扫描一次；`demo` 把 4 个人造场景发给 Jev（不含真实屏幕内容）；`capture x y w h out.png` 截图；`texts x y w h` 读区域内文字。
