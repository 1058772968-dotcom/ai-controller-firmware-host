# 给同事：五分钟跑起来（START HERE）

这是「呆毛语音 Coding」电脑端上位机的源码。功能一句话：**按住手柄/麦克风说话 → 电脑上转成文字 → 自动填进你选的目标 Agent（Claude Code、Codex、Cursor、任意应用）→ 可发送。**

## 0. 需要什么

- macOS（在 macOS 27 / Apple 芯片上开发验证过）
- **Chrome**（要用 Chrome 的 WebHID 和麦克风；Safari 不行）
- **Node 20 以上**（`node -v` 看一眼，没有就 `brew install node`）
- 可选：AI 控制器板子（E24）。没有板子也能先跑通「说话 → 识别 → 填进 Agent」，用电脑麦克风代替。

## 1. 三步启动

```bash
# 1) 解压后进目录
cd voice-coding

# 2) 双击（或在终端里跑）启动脚本
./start.command
```

3) 浏览器会打开一个应用窗口。第一次要点两个授权：

- **麦克风**：点「重新读取设备」或直接按住说话时允许；
- **辅助功能**：系统设置 → 隐私与安全性 → **辅助功能**，把 **Google Chrome**（或你用的终端）勾上。没有这一步，它打不进别的应用。

## 2. 换成你自己的密钥

源码里**没有**任何密钥，跑起来后需要在页面里填一次：

1. 到阿里云百炼控制台拿一个 API Key（形如 `sk-...`）。
2. 页面右上角「设置」→「语音转文字」→ 把 key 粘进输入框 → 点「存进钥匙串」。
3. 默认端点是百炼公开域名 `https://dashscope.aliyuncs.com`；如果你的 key 属于某个专属 workspace，改 `~/.voice-coding/config.json` 里的 `asr.baseUrl`（或设环境变量 `VOICE_CODING_ASR_BASE`）。

密钥只存进 **macOS 钥匙串**（服务名 `voice-coding-bailian`），不进源码、不进配置、不进日志。

## 3. 没板子怎么先试

设置里把「**只允许板载麦克风**」关掉，就能选电脑内置麦克风；界面会明说「说话内容会送云端识别」。试通流程后再插板子、把开关打开。

有板子的话：烧带音频的联调档（系统里出现 `Held-key microphone`），页面点「连接手柄」选 `AI KEY E24`，然后**按住 V 说话、松手出字**；L 发送、R 清空。

## 4. 数据去哪了

- 录音只在内存里，**不落盘**；识别时把这一段音频发到你自己配置的百炼端点。
- 识别出的文字会写进日志：`~/.voice-coding/logs/日期.log`（本机）。
- 配置在 `~/.voice-coding/config.json`。

## 5. 已知情况（别当 bug 踩）

- **接管手柄时板子当不了鼠标**：固件规定 HOST 模式下不发鼠标报告。点「交还指针」还回去，但那样按 V 也不开麦。
- **HID 命令通道会哑掉**：页面开合多次后接管会超时，点面板上的「重置手柄」（走 USB 重枚举）或拔插一次板子即可，页面会自动重连。
- 录制的是**板载麦克风**；板子固件的隐私闸门是「按住 V + 主机 HOST + 已请求录音」三条同时成立才放声。如果你烧的固件把闸门放宽了，勾选取消「只允许板载」也照样能用。
- 剪贴板还原只支持文本；Cursor / VS Code 的 AI 输入框焦点要自己点进去。
