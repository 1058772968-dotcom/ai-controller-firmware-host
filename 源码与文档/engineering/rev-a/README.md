## 文件

- `spec/requirements.json`：逐项需求及验收层级。
- `spec/board.json`：硬件与固件共用引脚、设备和时序。
- `spec/source-manifest.json`：设计输入快照的 SHA-256。
- `mechanical/`：FreeCAD 原生模型、交换和打样文件。
- `electrical/`：KiCad 原生工程、项目库和制造导出。
- `firmware/`：ESP32-S3 固件及与平台无关的控制核心。
- `host/`：电脑端协议与实际可执行的联调工具。
- `tests/`：针对输入归属、失联、互斥和确认链的测试。
- `reports/`：真实命令、校验报告和待办状态。
