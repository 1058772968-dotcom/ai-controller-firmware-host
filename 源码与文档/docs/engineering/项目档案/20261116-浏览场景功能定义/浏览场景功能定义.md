## 0. 前提：躺着刷和坐在桌前有什么不同

| 条件 | 带来的问题 |
|---|---|
| 只有手柄，没有键盘 | 搜索、评论、写意图都只能靠语音（V） |
| 陀螺仪指向 | 比鼠标抖，小图标难点准（小红书的收藏、点赞图标只有约 20 px） |
| 单手、刷得久 | 滚动是最频繁的动作，最累 |
| 离屏幕远 | 小字看不清 |

一条已定的原则（V0.3）：**L / R 平时就是普通鼠标，不藏指令。** 下面所有新能力都要“主动进入、看得见、R 能取消”。

## 1. 用户旅程与痛点

| 阶段 | 用户在做什么 | 痛点 | 严重度 | 对应功能 |
|---|---|---|---|---|
| 进入 | 打开网站、搜索 | 没有键盘，打字难 | 高 | B1 语音搜索 |
| 浏览 | 滚动信息流 | 一直倾斜滚动手累；广告和无关内容多，要一条条看 | 高 | B2 目标模式、B3 跳到下一条相关的 |
| 判断 | 点开笔记、翻图集、读长文 | 小按钮点不准；长文找不到重点；图集箭头太小 | 高 | B4 点击预判与吸附、B5 页面筛查与段落定位、B6 图集翻页 |
| 互动 | 点赞、收藏、评论、关注 | 点错（误点关注、广告）；评论要打字 | 中 | B4 + 写操作确认；语音评论先预览 |
| 干扰 | 弹窗、登录墙、推广 | 关闭按钮小、位置不固定 | 中 | B7 关闭干扰 |
| 收藏 | 存下喜欢的 | 各平台收藏夹各管各的；收的时候不记为什么收 | 高 | K1 圈选入库 + 意图 |
| 整理 | 收多了 | 乱，找不到 | 中 | K2 自动归类、项目归属、去重 |
| 取用 | 做 PPT、给 agent | 想不起收过什么，要一张张翻 | 高 | K3 按任务召回、K4 打包给 agent |
| 复盘 | 隔一段时间 | 收了不用，库变成垃圾场 | 低 | K5 用过 / 没用的回流 |

## 2. 三个场景

### 2.1 刷小红书找参考（主线，对应演示脚本）

1. **语音搜索**：按住 V 说“帮我搜索好看的 PPT 排版”，松开核对文字，L 确认 → 聚焦搜索框、输入、回车（B1）。
2. **设定目标**：搜索词自动成为“当前目标”；也可以随时说“我要找奶油风配色”改目标。
3. **刷结果**：Jev 给屏上每张卡片打相关度，相关的加绿边，无关的变暗（B2）；“下一条”跳到下一张相关卡片，不用一直滚（B3）。
4. **点开笔记**：光标靠近收藏、点赞时出现绿框，L 点准（B4，预判已有）；图集用 S 按住左右拨动翻页（B6，沿用 V0.3 翻页手势）。
5. **圈选入库**：长按 S 圈住排版（现在用 ⌃⌥C 代替），按住 V 说“这个排版好看，放进 PPT 参考”→ Jev 判类别为“排版”、项目为“PPT”（K1、K2）。
6. **交给 agent**：在 agent 里按住 V 说“根据我的参考重新生成我的 PPT”→ 灵感库按“PPT”召回最相关的几条（K3），打包成图片 + 意图 + 链接（K4），发送前预览，L 确认。

| 功能 | 手柄操作 | Jev 判断什么 | 优先级 |
|---|---|---|---|
| B1 语音搜索 | 按住 V 说，L 确认 | 这句话是“搜索”还是别的动作；搜索框是哪个元素 | P1（要 V 键） |
| B2 目标模式 | 圆盘里打开 / 关闭 | 每张卡片和当前目标有多相关；是不是推广 | P0 |
| B3 下一条 | 圆盘“翻页”或 S 拨动 | 用 B2 的结果，代码跳过去，不另问 | P2 |
| B4 点击预判与吸附 | 光标停住看绿框，L 点击 | 你要点哪个（已有） | P0 |
| B6 图集翻页 | S 按住拨动 | 不需要，代码找图集的左右箭头 | P2 |
| B7 关闭干扰 | 出现弹窗时提示，L 确认关闭 | 弹窗里哪个按钮是“关闭 / 暂不登录” | P0 |
| K1 圈选入库 | 长按 S 圈，按住 V 说意图 | 类别、标签、归属项目（类别已有） | P0（快捷键）/ P1（语音） |

### 2.2 网页找资料

1. **搜索**：同 B1。
2. **看结果页**：Jev 给每条结果标相关度，并判断是不是广告或拼凑出来的垃圾页（B2 的结果页版）。
3. **打开网页先筛**：先问一句“这页有没有我要的”（B5），没有就提示返回；有就定位到最相关的段落并高亮，不用从头读。
4. **摘录**：圈选段落入库，圈内文字从页面读出来（不只是截图），同时记网址和段落位置，回看时直接跳回原段落（K6）。
5. **多页汇总**（P2）：把几条摘录打包交给 agent 总结。Jev 不写文字，总结由 agent 做。

### 2.3 刷推特

1. **时间线**：目标模式下标出和目标相关的推文；单独判断是不是推广。
2. **长串推文**：Jev 判断哪几条是主干、哪些是闲聊回复，折叠后者。
3. **外语**：翻译交给浏览器自带翻译或 agent，Jev 不生成文字。
4. **收藏**：书签不够用时圈选入库，带作者、链接和原文。
5. **写操作**（点赞、转推、回复、关注）：一律用户按 L 确认，不自动做。

### 2.4 三个通用功能（11-16 用户补充）

这三个功能不限于某个网站，小红书、B 站、推特、普通网页都用得上。

#### F1 随处快速搜索

**要解决的事：** 在任何页面上冒出一个问题，不用找搜索框、不用打字，直接搜。

| 步骤 | 做什么 |
|---|---|
| 1. 触发 | 按住 V 说“搜一下 XXX”“小红书搜 XXX”“B 站搜 XXX”“谷歌一下 XXX”。按键接好之前用快捷键弹一个小输入框代替 |
| 2. 决定去哪搜 | 话里点了名就去那个网站；没点名就在当前网站搜（在小红书笔记页说“搜一下”，就搜小红书）；当前页面没有搜索功能时用默认搜索引擎。说“这页里找 XXX”就在当前页里查找；说“我收过的 XXX”就搜灵感库 |
| 3. 搜索词 | 代码从转写里去掉“帮我搜一下”和网站名，剩下的就是搜索词，松开 V 时显示出来让你核对 |
| 4. 执行 | 优先直接打开该网站的搜索结果网址（最快，不用点界面）；没有现成网址的网站，就跳到首页，找到搜索框，输入后回车 |
| 5. 接着刷 | 搜索词自动成为“当前目标”，结果页直接进入目标模式（B2） |
| 6. 回去 | 记住从哪一页跳过来的，说“回去”或在圆盘里选“返回”就回到原页面原位置 |

- **Jev 判断：** 只在去向拿不准时问一次（J10），比如“帮我找上次那个奶油风客厅”，是搜小红书还是搜灵感库。点了名的、在当前网站搜的，代码直接定，不问。
- **搜索框在哪：** 走第 4 步的界面路线时，搜索框由代码按辅助功能角色（搜索框、文本框）和占位文字找；同一页有多个输入框时，再交给 Jev 选（沿用 J1）。
- **各网站的搜索结果网址格式未核实**，实现前逐个确认，并写进各网站的配置里。
- **待拍板：** 在当前标签页跳转（返回靠浏览器后退，躺着操作最省事），还是新开标签页。

#### F2 图片左右划，快速翻页

**要解决的事：** 小红书图集、推特图片、B 站动态配图、网页大图浏览，手指够不着小小的左右箭头。

| 操作 | 效果 |
|---|---|
| 光标在图片上，按住 S 往左或往右拨一下 | 翻一张（沿用 V0.3 的拨动翻页手势） |
| 按住 S，手腕保持偏着不回正 | 连续往下翻，偏得越多翻得越快（像倾斜滚动一样分档）；回正或松开就停 |
| 翻页时 | 显示“3 / 9”这样的进度；到第一张或最后一张就停，不跳到别的内容 |

- **怎么认出是图片：** 代码看光标下的元素，满足三条中的一条就进入图片模式：是大图、旁边有“上一张 / 下一张”按钮、在图片浏览层里。普通网页还是按 V0.3 的“上一屏 / 下一屏”翻页。
- **怎么翻：** 先发键盘的左右方向键（大多数图片浏览层支持）；不起作用再按“下一张”按钮；还不行就对图片区域发横向滚动。
- **Jev：** 一般用不到。按钮没有文字、认不出哪个是“下一张”时，才让 Jev 选（J12）。
- **和 V0.3 的冲突（待拍板）：** V0.3 规定拨动翻页“按住多久也只翻一次”。这里提议只在图片模式里，把“按住并保持偏转”定义成连续翻。
- **按键接好之前：** 用快捷键 ⌃⌥← / ⌃⌥→ 测翻页逻辑。也可以试一个开关：打开后，光标在图片上快速左右划一下就翻一张。这个容易误触，默认关。

#### F3 点赞、收藏、投币等快捷互动

**要解决的事：** 互动按钮小，而且离内容远（B 站投币在视频下方）；还容易点错，比如把评论的赞当成笔记的赞。

| 网站 | 动作 |
|---|---|
| 小红书 | 点赞、收藏、评论、关注、分享 |
| B 站 | 点赞、投币（1 或 2 个）、收藏、三连、关注 |
| 推特 | 点赞、转推、书签、回复、关注 |

**三种触发方式：**

1. **直接点：** 光标指过去，吸附绿框（B4）帮你点准小图标。这是基础。
2. **语音：** 按住 V 说“点赞”“收藏这个”“投两个币”“三连”。
3. **圆盘：** 圆盘里的“AI 操作”展开一圈当前网站的互动动作。V0.3 的六个固定入口不变。

**对哪条内容操作：**

- 信息流里，按下 V 那一刻光标下的那张卡片；
- 详情页（笔记页、视频页、推文页）里，就是页面的主内容，不是评论区里的某一条。

代码先在这条内容的范围里，按按钮文字和图标说明找对应按钮；范围内有多个“赞”（比如笔记的赞和评论的赞）时，交给 Jev 选（J11）。

**做之前先看状态：** 读按钮当前是否“已赞 / 已收藏”。已经赞过还说“点赞”，就提示“已经赞过了”，不会点一下变成取消。

**按风险分两档确认：**

| 档位 | 动作 | 确认方式 |
|---|---|---|
| 能撤销、只影响自己 | 点赞、收藏、书签 | 你明确下了指令就执行；之后 3 秒内按 R 撤销 |
| 撤不回或会公开 | 投币、三连（含投币）、关注、转推、评论、分享 | 先预览“将给《某视频》投 2 个币”，按 L 确认才执行 |

- **执行后回读：** 确认按钮状态真的变了才提示完成，沿用“没收到确认就不提示完成”。
- **“收藏”和“放进灵感库”分开：**
  - 说“收藏”是平台收藏；
  - 说“放进参考 / 灵感库”是存进灵感库；
  - 设置里可以选“平台收藏时同时存一份进灵感库”。
  - 话里两种意思都可能时，由 Jev 判断（J11）。
- **不批量、不自动：** 一次指令只对一条内容生效。不提供“给这一屏全部点赞”这类功能，也不会根据相关度自动点赞（平台规则和账号安全）。

## 3. Jev 用法清单

Jev 只做判断：选哪个、是不是、有多相关。执行都由代码完成。

| 编号 | 用在哪 | 题型 | 发给 Jev 的状态 | 选项 / 输出 | 什么时候问 |
|---|---|---|---|---|---|
| J1 | 点击预判（已有） | Choice + Noul | 指针运动、附近可点元素（类型、文字、距离、方向）、当前目标 | c1…cN + 都不是；是否在瞄准 | 光标停住约 0.55 s |
| J2 | 卡片相关度 | 每张卡片一个 Score，外加一个“是不是推广”的 Noul，一次请求并行 | 当前目标、卡片标题、作者、点赞数、图片说明 | 四级：无关 / 沾边 / 相关 / 正是要找的 | 滚动停下且屏上卡片变了 |
| J3 | 页面筛查 | Noul | 目标、页面标题、正文前几段 | 这页有没有答案 | 打开页面后一次 |
| J4 | 段落定位 | Choice | 目标、带编号的段落 | 段落编号 + 都不是 | J3 判为“有”时 |
| J5 | 语音意图 | 动作一个 Choice，参数一个 Choice（指的是哪张卡片、哪个元素） | 转写文字、按 V 时锁定的目标、屏上候选 | 搜索 / 打开 / 收藏到灵感库 / 点赞 / 返回 / 下一条 / 发给 agent / 都不是 | 松开 V |
| J6 | 灵感分类 | 类别 Choice（已有）；每个标签一个 Noul；项目 Choice | 意图、来源、圈内文字、你的项目列表 | 类别、标签、项目 | 入库时 |
| J7 | 去重 | Noul | 新条目和最相似的几条旧条目 | 是不是同一个 | 入库时 |
| J8 | 按任务召回 | 每条灵感一个 Score | 当前任务（agent 里的输入、PPT 标题）+ 每条灵感的意图、类别、文字 | 四级相关度 | 取用时 |
| J9 | 关闭干扰 | Choice | 弹窗里的候选按钮 | 哪个是关闭 / 暂不登录 / 都不是 | 检测到浮层时 |
| J10 | 搜索去向（F1） | Choice | 转写文字、当前网站 | 当前网站 / 小红书 / B 站 / 推特 / 默认搜索引擎 / 当前页内查找 / 灵感库 | 话里没点名、代码定不下来时 |
| J11 | 互动动作与目标（F3） | 动作一个 Choice；目标按钮一个 Choice；“已经做过了吗”一个 Noul | 转写文字、锁定的那条内容、范围内的候选按钮及其状态 | 点赞 / 收藏 / 投币 / 三连 / 关注 / 转发 / 书签 / 评论 / 放进灵感库 / 都不是；哪个按钮 | 松开 V，或范围内有多个同类按钮时 |
| J12 | 认翻页按钮（F2） | Choice | 图片周围的候选按钮 | 上一张 / 下一张 / 都不是 | 方向键不起作用、按钮又没有文字时 |

**控制成本和延迟：**

- 同一屏的问题合并成一次请求（TypeSafe 文档：合并后更快更省）。
- 滚动中不问，停下来才问；卡片内容没变不重问，结果按卡片缓存。
- 只在白名单网站上启用。
- 已有基线：单次点击预判约 1000 个输入 token、中位 0.4 s。J2 一屏 10 张卡片要多少 token、多久，**未测**。

## 4. 灵感库怎么更好用

原则：**收的时候多花 2 秒记“为什么”，用的时候少花 2 分钟去找。**

| 环节 | 功能 | 说明 |
|---|---|---|
| 收 | K1 圈选 + 一句意图 | 已有：截图、来源、网址、圈内文字、意图文字。缺：语音说意图（要 V 键） |
| 理 | K2 自动整理 | 已有类别。**11-16 夜已加**：多标签（#标签 + Jev 从用过的标签里挑）、归属项目、去重合并（J6 + J7 一次请求） |
| 找 | K3 按任务召回 | 在 agent 或 PPT 里说“用我的参考”，Jev 给每条灵感打相关度，前 5 条浮出来。“上周在小红书收的配色”这类按时间、来源、类别的筛选由代码做，不用问模型。**11-16 夜已加键盘版**：灵感库里写任务召回 + 类别 / 项目 / 标签 / 来源 / 时间筛选 |
| 用 | K4 打包给 agent | 已有单条复制、拖拽。**11-16 夜已加**：多条打包（按类别分组）、导出文件夹 |
| 回流 | K5 用过 / 没用 | 记下 agent 用了哪几条、你采纳了哪条，用来改进召回排序；长期没用过的定期提醒或归档。**11-16 夜已加**：复制 / 拖出 / 打包计“用过”次数，手动归档 30 天没用过的；“采纳了哪条”和用它改召回排序未做 |
| 回看 | K6 回到原处 | 点卡片打开原链接；网页记段落位置，直接跳回原段落。**11-16 夜已加**：用圈内文字做 `#:~:text=` 片段链接 |

## 5. 边界

- **辅助，不代刷**：Jev 只标注和建议。点赞、收藏、关注、评论、转发等写操作由用户按 L 确认，不自动批量做（涉及平台规则和账号安全）。
- **L / R 不藏指令**：吸附只在“精准辅助”打开、而且绿框可见时生效，只把这一次点击挪到绿框里的元素上；光标在框外就照常点击。默认开不开，**待拍板**。
- **隐私**：发给 Jev 的是页面文字和元素位置，不发截图；只在白名单网站（小红书、Google、推特等）启用；网银、密码管理器、系统设置一律不读、不发。
- **没把握就不动**：置信度低于阈值只显示橙框，不吸附，也不自动执行。

## 7. 怎么判断有没有用

- **点击**：每 100 次点击的误点次数，开吸附和关吸附对比。
- **找内容**：从开始搜索到收下第一条有用灵感，用了多久。
- **灵感库**：入库后被召回、被采纳的比例；召回前 5 条里被采纳的比例。
- **成本**：每刷一小时 Jev 请求多少次、用多少 token；延迟的中位数和 90% 分位。

## 8. 拿不准 / 待验证

- 小红书网页版、推特网页版在 Chrome 里能读到多少界面信息（卡片标题、按钮文字），**未测**。读不到就只能截图交给 Jev 看图（图片输入还在预览阶段），而截图上云的边界还没定。
- 只有图片、没有文字的卡片，Jev 光靠文字判断相关度没有依据。
- Jev 对中文内容相关度打分准不准，一屏卡片要多少 token、多久，**未测**。
- 吸附算不算改变了 L “普通鼠标”的定位，**待拍板**。
- 平台规则：读取页面一般问题不大，自动写操作有风险。本定义不包含任何自动写操作。
- F1 各网站搜索结果网址的格式，**未核实**；有的网站可能要登录才能看搜索结果。
- F2 小红书、推特、B 站的图片浏览层是否都支持左右方向键，**未测**。
- F3 互动按钮能不能读到“已赞 / 未赞”状态，**未测**；读不到就无法防止误取消，只能在执行后回读时提示。
- 待拍板：F1 在当前标签页跳转还是新开；F2 图片模式里“按住保持偏转 = 连续翻”这个 V0.3 例外；F3 圆盘“AI 操作”里放互动动作，以及“平台收藏时同时存进灵感库”默认开不开。
