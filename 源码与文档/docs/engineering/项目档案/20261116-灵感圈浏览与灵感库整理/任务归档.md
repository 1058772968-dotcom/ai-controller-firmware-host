## 做了什么

### 浏览部分

| 编号 | 快捷键 | 做法 |
|---|---|---|
| B2 目标模式 | ⌃⌥G | 读指针所在网页看得见的部分（≤ 4000 个元素），先找 article（推文），没有就找“至少 3 个宽度相近的兄弟卡片”（信息流、搜索结果）；每张卡片一个 Score（无关 / 沾边 / 相关 / 正是）+ 一个“是不是推广”的 Noul，一次请求；相关的绿框，无关和推广压暗；滚动时撤标注，停下 0.5 s 重扫；按“目标 + 卡片文字”缓存 |
| B3 下一条 | ⌃⌥N | 指针下方第一张相关卡片（同一行取右边），滚进视野、指针移到卡片中间；这一屏没有就往下翻一屏 |
| B7 关闭干扰 | ⌃⌥X | 弹窗 = `role=dialog` / 系统表单，或 class / id 含 modal、dialog、popup、mask 等；嵌套时用最具体的那个。按钮只收“关闭、×、暂不登录、以后再说、跳过、取消”和 class 含 close / dismiss 的；含登录、关注、确定、购买、删除等字的一律不按；弹窗右上角无文字小按钮按位置收；多个候选问 Jev（J9）；按后 0.6 s 回读；认不出按钮时发一次 Esc，没弹窗什么都不做 |
| F1 联动 | ⌃⌥S | 搜网站后搜索词当目标，2.5 s 后自动开目标模式（定义 F1 第 5 步，设置里可关） |

### 灵感库整理

| 编号 | 做法 |
|---|---|
| K2 理 | 新字段全是可选：标签、自动标签、项目、可能重复、用过次数、归档、整理时间。入库时一次请求问：类别 Choice、项目 Choice（有项目列表才问）、用过的标签每个一个 Noul（≤ 12）、最像的 ≤ 3 条旧灵感每条一个“是不是同一条” Noul；阈值：标签 0.6、重复 0.7、项目 0.5。用户自己定的项目、否认过的重复不覆盖。编辑框里合并或否认 |

## 已知限制

- 卡片查找靠结构规则（article / 3 个以上宽度相近的兄弟节点），真实网站的结构可能不同；只有图片、没有文字的卡片 Jev 没有依据（定义第 8 节）。
- 关闭弹窗只认中英文常见写法；网站把关闭做成无文字、无 class、又不在右上角的按钮时认不出，会发 Esc。
- 召回一次最多 48 条（筛选后最近的）；更多条目要先用筛选缩小。
- 打包复制的剪贴板是“文字 + 文件”多项，不同 agent 输入框取用方式不同，未逐个试。
- 指针移到下一张卡片会移动系统光标（陀螺仪是相对移动，不冲突，但要用户确认手感）。
